# brand/

Physical brand asset files — logos, color palette definitions, typography files, icon sets. Every channel (`website/`, `ads/`, `social/`, `email/`, `decks/`, …) references these with relative paths like `../brand/logo.svg` or `../../brand/palette.json`.

Brand GUIDELINES (how to use these assets: voice, visual principles, layout rules, dos and don'ts) live in `docs/brand/` as markdown — this folder is just the physical assets.

See `CLAUDE.md` §2 for where `brand/` sits in the overall repo layout.
