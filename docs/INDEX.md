# docs/ — PRIVATE ONLY

The source of truth for all written content in this project: strategy, research, briefs, decisions, copy drafts and final approved text, brand guidelines, process docs. Nothing in `docs/` is ever publicly mirrored — this folder is never listed in `.sync-public.yml`.

Every `.md` file here starts with YAML frontmatter (schema in `CLAUDE.md` §2). Channel deliverables (a LinkedIn post's rendered screenshot, a sent email, a slide deck) live in their respective top-level channel folders; `docs/` holds the canonical text those deliverables render or reference.

See `CLAUDE.md` §2 for the canonical subfolder taxonomy, the "split at three" rule, and the frontmatter schema.

## Contents

- `home.md` — Home page spec; renders to `website/home.html`.
